One-time import for this production league only, from season screenshots, before go-live, after the admin maps every first name to a current member or a past member who still counts. Each screenshot is one season of first names across weeks. The filename is the season year. A cell that names a team is that person's pick. None of those screenshots are the current season in the app. The import prints what it read from each screenshot, and Kyle checks that reading before any of it is written to the database. Green = a win, 1 point. Pale blue = a win against the jailed team, 2 points. Red with a team = a loss, 0 points. An empty red cell = no team selected, a real loss, including Biggest Loser, 0 points. Yellow or orange = an invalid pick, and it counts as a loss, 0 points. A plain CSV is the wrong file: it drops the color. A season with no screenshot is omitted and does not block go-live.
