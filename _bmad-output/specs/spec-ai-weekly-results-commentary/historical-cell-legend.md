# Historical cell legend

Outcome for the one-time screenshot import is the cell fill. Each file is one season of first names across weeks, and the filename is the season year. A cell that names a team is that person's pick. These files are not the current season in the app. A plain CSV is rejected because it drops the fill.

These outcomes stay in the loaded book for the Tuesday digest. No app page shows past-season win/loss records or past-season biggest loser points.

| Fill | Reading | Points |
| --- | --- | --- |
| Green | A win | 1 |
| Pale blue | A win against the jailed team | 2 |
| Red, with a team | A loss | 0 |
| Red, empty | No team selected. A real loss, including Biggest Loser, in the same class as a submitted loss. | 0 |
| Yellow or orange | An invalid pick. Counts as a loss, same as a red cell with a team. | 0 |

Kyle checks a printed reading of each screenshot before any of it is written.
